# Show HN design-slop reference — the Krebs 16-pattern audit

**Why this doc exists:** when we launch a Show HN (kanji app, later PB), the landing
page gets scanned — by humans primed on this exact article, and increasingly by
tooling — for the visual fingerprint of "shipped whatever the LLM defaulted to."
This is the **design** analog of the text axis (`knowledge/ai-text-tells.md`,
automated by `lib/detell.js` and the `detell` CLI). Run both before any Show HN
goes live.

## The source
**Adrian Krebs — "Scoring Show HN submissions for AI design patterns"**
<https://www.adriankrebs.ch/blog/design-slop/> — hit the top of HN (~333 points).

**Method:** 1,590 Show HN landing pages run through Playwright, each scored against
16 DOM/CSS patterns designers flagged as AI tells.

**Breakdown of what's on Show HN right now:**
- High slop (4+ patterns): **22%** (347 sites)
- Medium (2–3 patterns): **32%** (508 sites)
- Low (0–1 patterns): **46%** (735 sites)

More than half the pages carry a visible AI fingerprint.

## The frame (quote verbatim — this is the load-bearing idea)
> "There is a difference between trying to craft your own design and just shipping
> with whatever defaults the LLMs output."

The tell is not any single element. It's a page **"generated by a chat interface
without an opinion."** The cure is the same as for text: have a point of view and
impose it. The killer analogy that ties this doc to `DETELL.md`:

> "colored left borders are almost as reliable a sign of AI-generated design as
> em-dashes for text."

## The 16 patterns (the checklist)

**Fonts**
- [ ] Inter for everything, especially centered hero headlines
- [ ] Space Grotesk / Instrument Serif / Geist combinations
- [ ] Serif-italic accent words inside an Inter hero

**Colors** (perma-dark is the single most common tell, 34% of pages)
- [ ] "VibeCode purple" as the dominant accent
- [ ] Perma dark mode with medium-grey body text + all-caps labels
- [ ] Low-contrast body text on dark
- [ ] Gradient backgrounds and colored glows / box-shadows (27%)

**Layout**
- [ ] Centered hero with generic sans
- [ ] Badge above the H1
- [ ] Colored borders (top or left) on cards  ← the em-dash-of-design
- [ ] Identical icon-topped feature cards (22%)
- [ ] Numbered 1-2-3 step sequences
- [ ] Stat-banner rows
- [ ] Emoji-icon sidebars / navigation
- [ ] All-caps headings / labels

**CSS**
- [ ] shadcn/ui defaults
- [ ] Glassmorphism (backdrop-blur, translucent panels)

Score like Krebs: 0–1 present = clean, 2–3 = mild, 4+ = heavy. Aim for 0–1.

## The anti-slop signature (what a clean, opinionated page looks like)
The choices that *invert* the fingerprint, drawn from the kanji-app demo audit
(2026-07-19), which scored low-slop:
- Light mode (dodges the #1 tell), or a genuinely designed dark theme — not the default
- `system-ui` / native font stack, not Inter/Geist/Space Grotesk
- High-contrast body text (near-black on white), not grey-on-dark
- No gradients, no glows, no glassmorphism, no shadcn defaults
- Left-aligned content, no centered hero, no badge-above-H1
- No icon-card grid, no marketing stat-banner, no emoji nav

## Kanji-app demo audit (2026-07-19) — worked example
Passed the big ones (light, system fonts, high contrast, no gradients/cards/shadcn/
glassmorphism/emoji/hero/badge). Two flags:
1. **Colored left border on `.result` cards** — *the* most-cited tell. Defensible
   here because it's semantic (green/amber/red = correct/slow/wrong state feedback),
   not decoration. Keep-or-cut is a judgment call; know a primed reader spots it first.
2. **All-caps labels** (`.eyebrow`, table `th`, `.band` pills) — cheap to neutralize
   (drop `text-transform:uppercase`). Do it.
Text axis (separate, see `DETELL.md`): ~39 em-dashes across the public prose
(README 12, NOTICE 11, demo/index.html 9, demo/README 7). Swap them before launch —
doubly important because the founder posted on the "Detecting LLM-Generated Texts"
HN thread and an em-dash-studded repo would be a self-own.

## Related conversion data (different source, same direction)
A separate 2026 study (digitalapplied.com, 2,000 pages) found pages with **>2
em-dashes per 100 words lose ~5% conversion**, and "delve / leverage / synergize /
optimize your experience" vocabulary loses ~8%. So the tells aren't just perception
— they measurably cost signups. (Attribution kept distinct from Krebs, who measured
design prevalence, not conversion.)
